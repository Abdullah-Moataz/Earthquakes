# Global Earthquake Analysis 🌍

## Overview

This project explores a global dataset of significant seismic events recorded since 1900. The goal is to understand historical earthquake patterns and explore how earthquake frequency, magnitude, depth, location, and time have varied.

## Analysis

The project focuses on:
- Locations with the highest earthquake frequency
- Strongest earthquakes by location
- Changes in earthquake frequency and magnitude over time
- Relationship between earthquake depth and magnitude
- Earthquake frequency by month and time of day
- Relationship between magnitude and number of reporting stations
- Comparison of different seismic event types

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The dataset contains global significant seismic event records since 1900, including information such as location, magnitude, depth, time, and event type.
